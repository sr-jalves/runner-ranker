# Security Policy

## Reporting Security Vulnerabilities

Se você descobrir uma vulnerabilidade de segurança neste projeto, **não abra uma issue pública**. 

Em vez disso, reporte de forma responsável para:

📧 **Email:** [seu-email@example.com]

Por favor inclua:
- Descrição da vulnerabilidade
- Passos para reproduzir
- Possível impacto
- Sugestões de fix (se tiver)

Vamos responder em até 48 horas e trabalhar com você para resolver o problema.

## Supported Versions

As seguintes versões recebem atualizações de segurança:

| Version | Suportada |
|---------|-----------|
| 1.0.x   | ✅ Sim    |
| < 1.0   | ❌ Não    |

## Security Best Practices

- Mantenha suas dependências atualizadas
- Use variáveis de ambiente para dados sensíveis
- Não commit de secrets ou credentials
- Revise o código antes de fazer merge

## Divulgação Responsável

Agradecemos por reportar vulnerabilidades de forma responsável e dar-nos tempo razoável para corrigir antes de divulgar publicamente.
