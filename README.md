# 🏃 Runner Ranker

Aplicação de controle de área através de racing, com estilo de jogo. Controle zonas competindo em corridas dinâmicas!

## ✨ Features

- 🎮 **Gameplay Dinâmico** - Sistema de corridas em tempo real
- 🗺️ **Controle de Área** - Compita pelas zonas do mapa
- 🏆 **Sistema de Ranking** - Acompanhe pontuação e posições
- ⚡ **Performance** - Construído em TypeScript para máxima segurança

## 🚀 Tech Stack

- **TypeScript** - Tipagem estática e segura
- **Node.js** - Runtime JavaScript
- **npm** - Gerenciador de pacotes

## 📋 Pré-requisitos

- Node.js 18+
- npm ou yarn

## 🔧 Instalação

```bash
# Clone o repositório
git clone https://github.com/sr-jalves/runner-ranker.git
cd runner-ranker

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.example .env

# Execute em desenvolvimento
npm run dev
```

## 🧪 Testes

```bash
# Rode os testes
npm test

# Com cobertura
npm run test:coverage
```
